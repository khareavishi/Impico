What the sensors check
Proximity trigger → weight change → correct compartment → sequence timing. All four must pass before a point is credited — a scan alone is never enough.

Guides

Segregate it right

Wet waste

Green bin

Food scraps, peels, tea leaves. No liquids — drain first, or the weight sensor may read a false volume.

Dry waste

Blue bin

Paper, cardboard, clean plastic. Flatten boxes so the proximity sensor reads a single clean insertion.

E-waste & batteries

Red bin

Never in a regular station. Drop these at the staff-room collection point only — IMPICO will flag a mismatch here.

Why the scan sometimes fails
IMPICO checks the physical event, not just the tap. A rejection usually means the wrong compartment or an object outside the expected weight range — not a system error.
